About
Who I am

Self-taught developer from Minsk, Belarus. I build practical tools — Telegram bots, automation scripts, embedded systems, and web services. I prefer shipping working code over perfect architecture.

Infrastructure

I run my own home server (Linux, Docker, nginx, PostgreSQL) and a VPS. Most of my projects run 24/7 in production. I manage everything from SSH.

Robotics

I compete at Robofinist and FIRA with self-built robots: an Arkanoid-playing robot (ESP32 + OpenCV + BLDC), a self-balancing robot (ESP32 + TMC2209 + MPU6050), and an autonomous RC car.

AI & Automation

I use LLMs as tools — building AI-powered bots, automating repetitive workflows, and exploring local models via Ollama. My main pet project is an AI persona system that mimics human conversation style.

How I Work

I communicate directly with clients and teammates, especially over long remote projects — clear about scope, timelines, and problems as they come up. I pick up new tools and domains quickly when a project calls for it.

Robotics & Competitions
Arkanoid Robot "Robo Arkasha" — Robofinist 2026
Autonomous robot that plays Arkanoid in real-time. Computer vision tracks a red ball via OpenCV (HSV calibration). ESP32 receives commands over UDP from a PC and drives a BLDC motor (ESC) + L298M side motors. The entire chassis is 3D-printed from PETG.
ESP32 OpenCV UDP BLDC + ESC PETG chassis LiPo 3S
Self-Balancing Robot — Robofinist 2026
Two-wheeled inverted pendulum robot. ESP32 + MPU6050 IMU + 2× TMC2209 stepper motor drivers with NEMA17 motors. PID control loop, tuned from scratch. Built with teammate Kostya, assembled and debugged over several months.
ESP32 TMC2209 MPU6050 PID NEMA17
Autonomous RC Car — FIRA Competition
RC car with autonomous navigation for FIRA competition. Computer vision-based control running on Linux. Developed in collaboration with team NDTP.
FIRA Computer Vision Linux Autonomous
