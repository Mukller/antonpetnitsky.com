## Структура

```
index.html        главная страница портфолио
cv-ru.html        CV на русском
cv-en.html        CV на английском
deploy.sh         деплой на сервер (nginx)
```

## Деплой

Статика раздаётся nginx'ом на домашнем сервере:

```bash
./deploy.sh
```
