Still worth knowing:
  * The router (192.168.0.1) proxies DNS and kept answering with the old
    address for as long as the old TTL lived (~8 min after the update), so a
    PC on the LAN can see the stale address briefly after a change.
  * The DDNS task runs every 15 min, so any future WAN change should self-heal
    within ~15 min. Check the task result before assuming DNS is broken.
  * Read this file, or query the box over the LAN (192.168.0.36, ssh by key),
