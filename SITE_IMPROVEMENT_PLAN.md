# Поэтапный план выполнения рекомендаций
Работа над сайтом antonpetnitsky.com
Создан: 20.09.2026
Статус: в процессе

---

## Этап 1: Безопасность и базовая проверка (выполнить сразу)
Цель: закрыть критичные пробелы из скриншота безопасности.

- [ ] Проверить index.html, deploy.sh, check.js на вшитые ключи/API ключи/секреты
- [ ] Проверить .env или переменные окружения (если используются на сервере)
- [ ] Добавить security headers в nginx (deploy.sh): X-Content-Type-Options, X-Frame-Options, CSP, HSTS, Referrer-Policy
- [ ] Проверить, что HTTPS принудителен (уже есть 301 redirect)
- [ ] Проверить robots.txt актуальность
- [ ] Проверить sitemap.xml актуальность

---

## Этап 2: Юридические страницы (выполнить сразу)
Цель: добавить Privacy Policy и Terms & Conditions.

- [ ] Создать privacy-policy.html (базовый текст для портфолио-разработчика, без сбора данных)
- [ ] Создать terms.html (базовые условия использования сайта)
- [ ] Добавить ссылки в footer index.html
- [ ] Обновить sitemap-pages.xml и sitemap.xml
- [ ] Добавить meta robots для этих страниц (если нужно исключить из индексации)

Цель: улучшить SEO и социальный шеринг.

- [ ] Проверить, что все страницы имеют уникальные title (index.html, about, projects, robotics, homelab, print3d)
- [ ] Проверить meta descriptions на всех страницах
- [ ] Добавить alt text ко всем изображениям в index.html и подстраницах
- [ ] Сжать og.png (сейчас 101KB) — оптимизировать или заменить на сжатую версию
- [ ] Добавить structured data (LocalBusiness или Person schema) в index.html

- [ ] Добавить team photo (если есть фото команды или автора в хорошем разрешении)

- [ ] Добавить sticky mobile CTA (кнопка, видимая при скролле на мобильном)
- [ ] Добавить cookie consent banner (базовый, без сложной логики)
- [ ] Добавить блок real reviews или testimonials

Цель: убедиться, что всё работает перед финальным запуском.

- [ ] Проверить spam protection (если добавлены формы)
