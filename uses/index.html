Uses.

Tools and gear I actually use day to day. Updated when something changes, not for fun.

Hardware
Workstation

Custom desktop, AMD Ryzen 7 5800X, 32 GB DDR4, RTX 3070 (mostly for Blender, sometimes ML). Two 27" monitors, one vertical.

Server

Home server, Xeon E3, 32 GB, ZFS mirror, runs 24/7. Details on the homelab page.

Laptop

ThinkPad T14, Linux. Carries it to school. The one thing I won't replace.

Phone

Mid-range Android. Syncthing for voice notes inbox, Telegram for everything else.

Software — daily
Editor

Neovim with LSP, no plugin manager (just lua files in ~/.config/nvim). Three custom plugins. The only IDE I trust.

Terminal

Alacritty + tmux + fish. SSH through tmux so sessions survive reconnects.

Browser

Firefox with uBlock Origin, no other extensions. 12 tabs max.

Notes

Obsidian vault synced via Syncthing, voice notes via the voice-notes bot.

Communication

Telegram (work, friends, school groups). Email for anything official. Phone calls for emergencies.

Software — server
OS

Debian stable. Updated on Sundays, after the backup has run.

Web

nginx + let's encrypt + certbot. Cloudflare is not in the stack.

Containers

Docker + compose. Logs to journald. Three named volumes, everything else is bind mounts.

Database

PostgreSQL 16. One master, no replicas. I have backups, I don't need replicas.

Cron

systemd timers, not crontab. Easier to read the logs, easier to disable a single job.

Services
AI

OpenRouter for the persona bot (stealth/ox-alpha), Ollama for local fallback (qwen3.5:4b on the GPU). One model for code, one for chat.

Email

Self-hosted Postfix + Dovecot. Two MX records on the home IP. Delivery succeeds for 90% of recipients, the rest need me to use a relay.

Git

GitHub for public code, Gitea for private. SSH keys only, no HTTPS tokens in CI.
